### ❌ 不可用

| 功能 | 状态与原因 |
|---|---|
| **音频（麦克风 / 扬声器 / 听筒）** | 声卡在（`0 [smartisanodin]`，1118 个 mixer 控件：`ADC2 MUX`、`DEC1 MUX`、`HPHL`、`HPHR`、`Earpiece`、`EAR_S`、`Ext Spk`、`SPK DAC`、`LINEOUT` 全在）；UCM 在（`/usr/share/alsa/ucm2/smartisanodin`，`alsaucm list _verbs` 能列出 `HiFi`。**PCM 打不开**：`hw:0,0 / plughw:0,0 / hw:0,2 / plughw:0,2` 播放、`hw:0,1 / plughw:0,1 / hw:0,4 / plughw:0,4` 录音，全部 `audio open error: Invalid argument`。

**根因**：UCM 的 HiFi verb **未激活**（`/etc/asound.conf` 与 `/etc/alsa/conf.d` 都是空的），DAPM 路由控件当前值全是 `ZERO`：
```
ADC2 MUX = ZERO    DEC1 MUX = ZERO    LINEOUT = ZERO
```

> **更正 045**：045 记的「麦克风 ✅ 可用 / 听筒 ✅ / 扬声器 ✅」是在**当年手工设过 mixer 路由的旧机**上验的。路由没有固化进镜像 ⇒ **全新刷机的 v0.9.9 上音频不可用**。

**修复方向（本次未做）**：激活 UCM HiFi verb（`alsaucm -c smartisanodin set _verb HiFi`）并固化（开机脚本 / udev）。设备无网，无法现场装 ffmpeg 之类的工具来辅助验证。
